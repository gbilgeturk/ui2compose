## Metric definitions

- `raw_detections`: detector output at the pipeline settings (conf 0.3, NMS IoU 0.7, the checkpoint's imgsz 640)
- `dedup_removed`: detections removed by postprocess.deduplicate_detections (v1.1.0 had no de-duplication step: 0)
- `emitted`: detections that appear in the generated Kotlin. v1.1.0: the leaves collected by the v1.1.0 generator (containers were dropped, a child of two parents was collected twice); v1.2.0: every leaf template plus every list container emitted as a LazyColumn (cross-checked against the trace comments of the generator)
- `emitted_by_class`: the emitted detections counted by detector class
- `duplicated_ids`: detection ids emitted more than once (id -> count)
- `dropped_ids`: detections that reach code generation but are not emitted
- `placeholders`: number of 'Unknown: <class>' placeholder texts in the Kotlin
- `xycut_fallback_nodes`: layout nodes where XY-cut found no cut on either axis and the fallback ordered the members (v1.1.0: zero-tolerance cuts; v1.2.0: cuts with the default tolerance cut_tol_frac selected on the validation split, 0.0)
- `xycut_fallback_nodes_tol0`: the same count with cut_tol_frac=0 (the zero-tolerance cut rule of v1.1.0), recomputed from the v1.2.0 graph: separates the effect of containment and de-duplication from that of the tolerance (v1.1.0: equal to xycut_fallback_nodes)
- `gap_tolerance_nodes`: v1.2.0 layout nodes with at least one cut that needed the tolerance (touching or overlapping by less than cut_tol_frac of the image extent)
- `box_composites`: containers with detected children, emitted as Box { container widget; children's layout } (v1.1.0: 'Box(' blocks in the Kotlin that are not 'Unknown' placeholders)
- `lazycolumn_composites`: list containers (ListView/RecyclerView) with detected children, emitted as LazyColumn { item { ... } }; a list without children is a leaf template and is not counted (v1.1.0: 'LazyColumn(' occurrences in the Kotlin)
- `parent_child_edges`: containment edges of the UI graph
- `spatial_edges`: above/below/left_of/right_of edges of the UI graph (inspection export, not read by code generation)
- `kotlin_lines`: len(code.splitlines()) of 4_GeneratedScreen.kt
